# BCanteen — Smart Foodcourt Ecosystem Platform

## Overview
BCanteen is a smart foodcourt ecosystem platform designed to help foodcourt management teams digitalize tenant operations, operational monitoring, and customer ordering systems without building their own application from scratch.

The platform centralizes foodcourt management, tenant coordination, operational monitoring, and food ordering experiences into one scalable ecosystem.

## Main Features
- Foodcourt Management System
- Tenant Operational Dashboard
- Live Order Monitoring
- Menu & Stock Management
- Pickup Code Verification
- Customer Order Tracking
- Analytics & Operational Monitoring

## Current Development Focus
Current development priorities focus on:
1. Admin System
2. Foodcourt Management System
3. Tenant Operational System

Customer-side implementation will be developed after the stabilization and testing of the core operational systems.
